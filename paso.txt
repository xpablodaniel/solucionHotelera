🎯 ¿Qué debe hacer Rooming?

Por ahora solamente organizar la información.

No debe:

decidir qué habitación asignar;
cambiar una habitación;
redistribuir pasajeros;
decidir camas;
juntar reservas distintas;
interpretar A/B/C como habitaciones.

Debe decirnos claramente:

Para cada reserva, ¿qué pasajeros están en qué habitación y qué sabemos físicamente de esa habitación?

1. La estructura que propongo

Crear:

mkdir -p src/business
nano src/business/rooming.js

Con:

/**
 * Construcción del Rooming
 *
 * Responsabilidad:
 * - Recibir reservas ya procesadas.
 * - Organizar pasajeros por habitación.
 * - Conservar información del inventario físico.
 * - Conservar asignaciones A/B/C cuando correspondan.
 *
 * IMPORTANTE:
 * Este módulo NO:
 * - asigna habitaciones;
 * - cambia habitaciones;
 * - decide disposición de camas;
 * - optimiza ocupación;
 * - interpreta las letras A/B/C;
 * - modifica las reservas originales.
 */


/**
 * Construye el rooming a partir de reservas procesadas.
 *
 * Una entrada del rooming representa una habitación
 * dentro de una reserva.
 */
function buildRooming(reservas) {

    if (!Array.isArray(reservas)) {
        throw new TypeError(
            "buildRooming espera un array de reservas."
        );
    }


    const habitaciones = [];


    for (const reserva of reservas) {

        if (!Array.isArray(reserva.habitaciones)) {
            continue;
        }


        for (const habitacion of reserva.habitaciones) {

            habitaciones.push({

                voucher: reserva.voucher,

                clasificacion:
                    reserva.clasificacion
                        ? reserva.clasificacion.tipo
                        : null,

                numero:
                    habitacion.numero,

                inventario:
                    habitacion.inventario
                        ? { ...habitacion.inventario }
                        : null,

                capacidad:
                    habitacion.inventario
                        ? habitacion.inventario.capacidad
                        : null,

                pasajeros:
                    Array.isArray(habitacion.pasajeros)
                        ? [...habitacion.pasajeros]
                        : [],

                cantidadPasajeros:
                    Array.isArray(habitacion.pasajeros)
                        ? habitacion.pasajeros.length
                        : 0,

                asignaciones:
                    Array.isArray(habitacion.asignaciones)
                        ? [...habitacion.asignaciones]
                        : []
            });
        }
    }


    return habitaciones;
}


/**
 * Devuelve la cantidad total de habitaciones
 * incluidas en el rooming.
 */
function countRoomingRooms(rooming) {

    if (!Array.isArray(rooming)) {
        throw new TypeError(
            "countRoomingRooms espera un array."
        );
    }

    return rooming.length;
}


/**
 * Devuelve las habitaciones de un determinado voucher.
 */
function getRoomsByVoucher(rooming, voucher) {

    if (!Array.isArray(rooming)) {
        throw new TypeError(
            "getRoomsByVoucher espera un array."
        );
    }

    return rooming.filter(
        room => room.voucher === voucher
    );
}


/**
 * Devuelve las habitaciones ocupadas por un
 * determinado pasajero/documento.
 *
 * Por ahora es una búsqueda simple.
 * Más adelante podremos incorporar otras reglas.
 */
function getRoomsByPassenger(rooming, numeroDocumento) {

    if (!Array.isArray(rooming)) {
        throw new TypeError(
            "getRoomsByPassenger espera un array."
        );
    }

    return rooming.filter(room =>
        room.pasajeros.some(
            pasajero =>
                pasajero.pax &&
                pasajero.pax.numeroDocumento ===
                    numeroDocumento
        )
    );
}


if (typeof module !== "undefined" && module.exports) {

    module.exports = {
        buildRooming,
        countRoomingRooms,
        getRoomsByVoucher,
        getRoomsByPassenger
    };
}
2. ¿Qué obtenemos?

Si tenemos nuestra reserva de ejemplo:

238 A → GOMEZ
238 B → ALBA
238 C → INES

el Rooming tendrá conceptualmente:

{
    voucher: "30243135",

    clasificacion: "CONTINGENTE",

    numero: "238",

    inventario: {
        piso: 2,
        codigoTipo: "III",
        tipo: "TRIPLE INDIVIDUAL",
        capacidad: 3
    },

    capacidad: 3,

    cantidadPasajeros: 3,

    asignaciones: [
        "A",
        "B",
        "C"
    ],

    pasajeros: [
        ...
    ]
}

Y una reserva individual:

109
GOMEZ
PEREZ

tendrá:

{
    voucher: "...",

    clasificacion: "INDIVIDUAL",

    numero: "109",

    inventario: {
        piso: 1,
        codigoTipo: "X",
        tipo: "DOBLE MATRIMONIAL",
        capacidad: 2
    },

    cantidadPasajeros: 2,

    asignaciones: []
}

Eso respeta perfectamente la regla que establecimos:

CONTINGENTE
→ puede tener A/B/C

INDIVIDUAL
→ no tiene A/B/C

🍚 Y una decisión importante

Todavía no estamos haciendo esto:

238 → cama 1 → GOMEZ
238 → cama 2 → ALBA
238 → cama 3 → INES

Eso viene después.

Primero construimos el rooming lógico:

238
 ├── capacidad: 3
 ├── pasajeros: 3
 ├── A
 ├── B
 └── C

Luego, con la composición de los pasajeros, podremos construir la disposición de camas.

Y ahí sí podremos representar casos como:

TRIPLE
├── matrimonio
└── hijo/a

o:

TRIPLE
├── amiga
├── amiga
└── amiga

sin confundir tipo de habitación, cantidad de pasajeros y disposición de camas.
